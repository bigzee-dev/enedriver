## Header

## contact form

Create a modern, proffessional contact form that will have these input fields

- name (required)
- email (required)
- phone number (not required)
- message (required)

Implement client side html validation e.g to check if the email address is in the form of the email.

The form will be submitted to a node api running at emailapi.deltaworx.co.bw
Handle all loading and error states and ui
